# Sprint_7
Тестирование API учебного сервиса Яндекс Самокат. 
Протестированы следующие ручки:
***Создание курьера***
1. Успешное создание курьера — при наличии всех обязательных полей.
2. Невозможность создать двух одинаковых курьеров — проверка уникальности.
3. Обязательные поля — для создания курьера требуется передать все обязательные данные.
4. Правильный код ответа при успешном создании — проверка статуса HTTP.
5. Ошибка при отсутствии обязательного поля — тестирование ошибок валидации.
***Логин курьера***
1. Авторизация курьера — успешный запрос возвращает ID курьера.
2. Корректность данных для авторизации — проверка всех обязательных полей.
3. Ошибка при авторизации с некорректными данными:
   - Некорректный логин.
   - Некорректный пароль.
   - Отсутствие обязательных полей.
   - Несуществующий курьер.
***Создание заказа***
1. Гибкость в выборе цветов:
   - Можно указать один цвет: BLACK или GREY.
   - Можно указать оба цвета.
   - Можно не указывать цвет.
2. Тело ответа содержит track — при успешном создании заказа.
***Список заказов***
1. Запрос к списку заказов — возвращается список всех заказов, созданных курьерами.
